# Phần 32 — Câu 621 đến 640

> Nền tảng: [Chương 0 — Bản đồ hệ thống](00-ban-do-he-thong.md)

---

## Câu 621 — Ảnh S3 us-west-1, **copy mọi object mới** sang us-east-1, ít ops

**Đáp án: A — S3 Cross-Region Replication.** CORS không copy. Lifecycle không copy Region. Lambda event tự viết.

---

## Câu 622 — SPA + DB, triệu user **4 giờ sáng**, còn lại ít; schema **đổi nhanh**; scale nhất (chọn hai)

**Đáp án: A DynamoDB on-demand + D S3+CloudFront.** Aurora Serverless cũng scale nhưng “rapidly evolve schema” = DDB. Auto scaling provisioned kém on-demand burst. EC2+EFS static thừa.

---

## Câu 623 — API GW REST, chống SQLi/XSS, ít ops

**Đáp án: B — WAF gắn API GW.** Shield = DDoS. CloudFront+WAF thừa bước.

**Tầng 3.** Câu 340.

---

## Câu 624 — 1500 user, AD on-prem, **không identity thứ hai**

**Đáp án: D — SAML 2.0 federation, map AD group → IAM role.** Cognito user pool không phải “giữ AD”. Cross-account không phải AD. 1500 IAM user = identity thứ hai.

**Tầng 10.** Câu 28, 484.

---

## Câu 625 — Nhiều ALB, **distribution rights theo thế giới**

**Đáp án: C — Route 53 geolocation.** Geoproximity = gần, không “quyền phân phối nước”. WAF không route theo nước (geo match chặn, không serve đúng content).

---

## Câu 626 — On-prem → S3, **tự validate integrity** sau transfer

**Đáp án: B — DataSync** (checksum). Snowball Edge “online” sai. File Gateway không phải verify job. TA không validate.

---

## Câu 627 — 2 DNS server, ~200 zone, 1M query/ngày, max HA, ít ops

**Đáp án: A — Route 53 hosted zone, import zone file.** Tự nuôi EC2 DNS ops.

---

## Câu 628 — Org nhiều account, multipart S3, report **incomplete MPU**, ít ops

**Đáp án: C — S3 Storage Lens.** Config/SCP/MRAP không metric MPU.

---

## Câu 629 — RDS MySQL production, upgrade version, test, **không mất data**, ít ops

**Đáp án: D — RDS Blue/Green Deployments.** Snapshot/DMS nặng hơn.

---

## Câu 630 — Job **1 lần/ngày, tới 2 giờ**, interrupt phải **làm lại từ đầu**, rẻ

**Đáp án: C — ECS Fargate + EventBridge.** Lambda 15 phút. RI 24/7 lãng phí. ECS on EC2 nuôi cluster.

---

## Câu 631 — Social graph (profile, relationship), monitor change, recommend

**Đáp án: B — Neptune + Neptune Streams.** QLDB = ledger. Kinesis tự pipe.

---

## Câu 632 — Data lớn, analyze hourly, nhiều EC2 Linux **nhiều AZ** sửa, storage **phình 6 tháng**

**Đáp án: C — EFS.** Glacier chậm. EBS một AZ / Multi-Attach hạn chế.

---

## Câu 633 — RDS PostgreSQL Multi-AZ, chậm vì **query**

**Đáp án: C — Read replica.** Standby Multi-AZ không đọc. Transfer Accel/Firehose vô nghĩa.

---

## Câu 634 — 10 GB telemetry/ngày S3, nhiều agency **account họ**, max security + ít ops

**Đáp án: C — Cross-account bucket access.** Không public. Không IAM user từng analyst. Không “S3 global tables”.

---

## Câu 635 — FSx ONTAP CIFS+NFS, DR Region 2, **cùng protocol**, ít ops

**Đáp án: C — ONTAP thứ hai + SnapMirror.** Backup restore không “cùng protocol live”. EFS/S3 đổi protocol.

---

## Câu 636 — S3 → SNS, xử lý event **scalable** rồi Lambda

**Đáp án: C — SNS → SQS → Lambda.** ECS/EKS/SMS thừa.

---

## Câu 637 — API GW, 0→500 RPS đột, persist < 1 GB key-value (chọn hai)

**Đáp án: B Lambda + C DynamoDB.** Fargate/ASG/Aurora nặng hơn.

---

## Câu 638 — Research data S3, share employee **toàn cầu**, secure, ít ops

Dump: presigned Lambda (A) scale kém từng file. IAM user 1:1 nặng. File Gateway on-prem. Transfer Family SFTP + custom IdP + Secrets — ops vừa.

Thực tế production hay dùng **Cognito/IAM Identity Center + S3**. Trong option: **A** ít ops hơn Transfer nếu URL ngắn. Đề “employees all over the world” + minimize ops → **A presigned** (hoặc D nếu cần SFTP lâu). Chốt **A** — generate URL, không nuôi SFTP/IAM user.

---

## Câu 639 — ALB, traffic **dồn một EC2**, latency

**Đáp án: A — Tắt sticky sessions.** NLB không sửa affinity. Thêm instance không cân nếu sticky.

---

## Câu 640 — Lambda tải/decrypt S3 KMS (chọn hai)

**Đáp án: B key policy allow Lambda role + E execution role có kms:Decrypt.** Resource policy Lambda không grant KMS. “Attach policy to function” (D) mơ hồ.

**Tầng 10.** Câu 550.
