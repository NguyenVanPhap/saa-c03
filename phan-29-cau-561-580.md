## Câu 561 — Website triệu request, giảm latency đọc DynamoDB, ít ops

**Đáp án: A — DAX.** Câu 361, 472.

## Câu 562 — EC2 VPC → DynamoDB **không internet** (chọn hai)

**Đáp án: B gateway endpoint + A route table entry.** Không ENI/SG (đó là interface).

**Tầng 9.**

## Câu 563 — EKS + K8s on-prem, **xem hết cluster** một chỗ, ít ops

**Đáp án: B — EKS Connector.** Container Insights chỉ AWS. EKS Anywhere không “primary xem hết”.

---

## Câu 564 — Ecommerce, PII, checkout, **DBA cũng không đọc** plaintext

**Đáp án: B — RDS + KMS *client-side* encryption.** Server-side KMS DBA/RDS vẫn decrypt được bằng role. EBS/S3/FSx không phải transactional store chuẩn.

---

## Câu 565 — MySQL on-prem transactional, **tương thích app**, **scale tự** khi demand

**Đáp án: C — DMS → Aurora + Aurora Auto Scaling (replica).** RDS elastic storage chỉ disk. Redshift/DDB phá tương thích.

---

## Câu 566 — Nhiều EC2 Linux 2 AZ, directory **hierarchical**, đọc/ghi **nhanh đồng thời** shared

**Đáp án: B — EFS.** S3 không POSIX. io2 Multi-Attach một AZ. Sync EBS tay.

---

## Câu 567 — Sensor HTTP cộng dồn usage theo tenant, managed, sẽ thêm component

**Đáp án: A — API GW + Lambda + DynamoDB.** SQL Express trên EC2 không managed.

---

## Câu 568 — Engineering drawings, cache load nhanh, **PB**

**Đáp án: A — S3 + CloudFront.** Glacier chậm. EBS không PB. Storage Gateway hybrid.

---

## Câu 569 — EventBridge rule → third-party API, **không thấy traffic**; kiểm tra rule/target

**Đáp án: A — CloudWatch `AWS/Events` (Invocations, FailedInvocations, TriggeredRules).** DLQ chỉ khi đã cấu hình. CloudTrail không phải metric invoke.

---

## Câu 570 — Thường 2 instance, **thứ Sáu** lên 6, ít ops

**Đáp án: B — ASG scheduled action.** Câu 333, 405.

---

## Câu 571 — REST API, **TLS 1.3**, cert **third-party CA cụ thể**

**Đáp án: A — Tạo cert máy local, CA ký, **import ACM**, HTTP API custom domain.** ACM không “create signed by third-party”. Lambda URL không custom cert third-party như API GW.

---

## Câu 572 — App traffic lệch, DX tới MySQL on-prem **≥ 2 GiB RAM**, migrate managed + **autoscaling**

**Đáp án: C — Aurora Serverless v2, min 1 ACU** (scale memory). Aurora provisioned 1 ACU không auto như v2. DynamoDB đổi API. RDS 2 GiB cố định.

---

## Câu 573 — Lambda Java 11, giảm cold start, **không latency cực nghiêm**, rẻ

**Đáp án: D — SnapStart.** Provisioned concurrency đắt. Timeout/memory không đủ.

**Tầng 4.** Câu 379.

---

## Câu 574 — RDS MySQL, chỉ **2 giờ cuối tuần**, tối ưu cost

**Đáp án: A — Aurora Serverless v2**, scale to 0 / min thấp. RI/ECS/EC2 nuôi 24/7 hoặc ops.

---

## Câu 575 — EKS+ALB, PostgreSQL **HA + tăng đọc**, ít ops

**Đáp án: C — RDS Multi-AZ *DB cluster*** (2 reader). Instance Multi-AZ không đọc standby. DynamoDB đổi engine. Cross-Region replica thừa.

**Tầng 6.** Câu 420.

---

## Câu 576 — API GW + Lambda, user **địa lý phân tán**, giảm latency

**Đáp án: D — Edge-optimized endpoint.** Private/Regional/Interface không CDN biên.

---

## Câu 577 — CloudFront, client dùng TLS, **auto tạo/renew** cert

**Đáp án: C — ACM + DNS validation.** Email validation kém auto. Security policy/OAC không cấp cert.

---

## Câu 578 — DynamoDB, ms → **μs**, cache, ít ops

**Đáp án: A — DAX.** Câu 561.

---

## Câu 579 — RDS PostgreSQL chỉ weekday giờ làm, tối ưu cost + ít ops

**Đáp án: A — Instance Scheduler on AWS** start/stop. Tắt backup nguy hiểm. RI 24/7 lãng phí.

---

## Câu 580 — On-prem **local disk** latency-sensitive, lift-and-shift, không đổi kiến trúc, rẻ

**Đáp án: D — EC2 + EBS gp3.** gp2 đắt/già. FSx đổi sang shared FS.
