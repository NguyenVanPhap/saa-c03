## Câu 474 — Nhiều VPC nhiều Region, phải **nói hết với nhau**, ít admin

**Đáp án: C — TGW mỗi Region + TGW peering.** Full mesh peering nổ. DXGW không phải mesh VPC. PrivateLink point-to-point.

## Câu 475 — ECS, shared FS durable, mount **mỗi AZ**, RPO 8h Region khác, **AWS Backup** replicate

**Đáp án: C — EFS Standard** (mount target mỗi AZ) + AWS Backup cross-Region. FSx Windows/ONTAP/OpenZFS backup được nhưng EFS là đáp án POSIX Linux + mount mọi AZ chuẩn.

## Câu 476 — IAM group theo phòng, quyền user mới **an toàn nhất**

**Đáp án: C — IAM policy least privilege gắn group.** Role không “attach group”. SCP không grant quyền user. Permission boundary là trần, không grant.

## Câu 477 — Policy ListBucket+DeleteObject trên `arn:...:bucket-name` — **không xóa được object**

**Đáp án: Thêm statement `s3:DeleteObject` trên `arn:...:bucket-name/*`.** ListBucket = resource **bucket**; DeleteObject = resource **object/***. Đừng `s3:*`.

**Tầng 10.**
