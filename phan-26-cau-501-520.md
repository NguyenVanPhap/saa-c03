# Phần 26 — Câu 501 đến 520

> Nền tảng: [Chương 0 — Bản đồ hệ thống](00-ban-do-he-thong.md)

---

## Câu 501 — Payment mỗi phút → data lake S3, **analyze realtime** rồi ingest, ít ops

**Đáp án: C — Firehose ingest + Kinesis Data Analytics realtime.** Glue không stream. API GW+Lambda thiếu sink lake managed. Streams+Lambda thiếu Firehose/Analytics gói sẵn.

**Tầng 5+7.** Câu 77.

---

## Câu 502 — CMS một EC2 + Aurora Multi-AZ + ảnh trên **EBS** (chọn hai)

**Đáp án: C EFS share ảnh + E AMI + ALB + ASG min 2 + CloudFront.** S3 “mount” không POSIX. NFS từ primary = SPOF. Global Accelerator kém CloudFront cho website ảnh.

---

## Câu 503 — SaaS đọc EC2/CloudWatch **account khách**, an toàn nhất

**Đáp án: A — Khách tạo IAM role read-only, trust account công ty.** Không lấy access key. Câu 418.

---

## Câu 504 — Hàng trăm account, nhiều VPC us-east-1, team mạng **một account**

**Đáp án: C — Transit Gateway ở account mạng.** Peering mesh không scale. NAT/internet không private. Transit VPC VPN cũ.

---

## Câu 505 — Batch đêm 0–6h, ASG On-Demand, job fail thì máy khác làm lại

**Đáp án: C — Spot** (interrupt được, retry). RI/SP 24h cho 6h/ngày lãng phí.

**Tầng 12.** Câu 290.

---

## Câu 506 — Upload ảnh social, traffic sự kiện, **scale nhất**

**Đáp án: C — Presigned URL, browser → S3.** Câu 110.

---

## Câu 507 — Ticketing global, latency update **< 1s**, **một** primary reservation **globally consistent**

**Đáp án: A — DynamoDB global tables.** Aurora/RDS replica bất đồng bộ > 1s. Serverless+DMS tự sync không consistent.

**Tầng 6.**

---

## Câu 508 — Windows EC2 us-west-1, DR us-west-2, RPO **24h**, tự động, ít admin (chọn hai)

**Đáp án: B DLM AMI lifecycle copy us-west-2 + D AWS Backup plan copy us-west-2, 2 lần/ngày.** On-demand copy (A/C/E) không tự.

---

## Câu 509 — Triệu request giả từ **ít IP**, SG **không deny**; cần chặn ngay

**Đáp án: B — NACL inbound deny** trên **web/public** subnet (ALB). SG không có deny. NACL app private không thấy IP client (thấy IP ALB).

**Tầng 9.**

---

## Câu 510 — App eu-west-1 ↔ DB ap-southeast-2, secure

**Đáp án: C — VPC peering + update route + SG DB allow **IP** app.** SG **ID không reference cross-Region**. TGW thừa cho 2 VPC.

---

## Câu 511 — Nhiều env PostgreSQL, dùng **½ buổi 8 giờ**, rẻ

**Đáp án: C — Aurora Serverless (On-Demand) PostgreSQL.** Pause/ACU khi không dùng. Câu 411.

---

## Câu 512 — Organizations, Backup, cần backup **mọi** resource, ít ops

**Đáp án: A — Config tìm untagged, tag programmatically, backup plan theo tag.**

---

## Câu 513 — Upload ảnh, resize nhiều device, traffic **không đoán**, HA scale

**Đáp án: A — S3 static + Lambda resize + S3.** ECS+SQS+EC2 nặng. Câu 63, 110.

---

## Câu 514 — EKS private endpoint only, node private subnet **không join cluster**

**Đáp án: B — Interface VPC endpoint** (EKS, ECR, STS, EC2, S3 gateway…). IAM role thiếu thường lỗi khác. Public subnet phá compliance.

---

## Câu 515 — Redshift phù hợp? (chọn ba)

**Đáp án: B encryption, C analytics theo giờ, E scale PB.** Không phải cache/API/OLTP global million QPS, không “secondary replica bằng một click” như vậy.

**Tầng 7.** Câu 2.

---

## Câu 516 — API tài chính, peak lớn, **latency thấp ổn định**, ít ops

**Đáp án: B — API GW + Lambda provisioned concurrency.** Reserved concurrency chỉ **giới hạn**, không giữ ấm. Câu 379.

---

## Câu 517 — Session Manager logs → S3 archive, hiệu quả nhất

**Đáp án: A — Bật S3 logging trong Session Manager.** Không qua CW/Firehose vòng.

---

## Câu 518 — RDS MySQL hết disk, **tăng disk không downtime**, ít effort

**Đáp án: A — Storage autoscaling.** Câu 276.

---

## Câu 519 — Consulting, **self-service** bộ tool chung cho khách

**Đáp án: B — Service Catalog.** CFN raw không portal/governance.

---

## Câu 520 — EC2 + DynamoDB, traffic **không đoán**, R/W vừa-cao

**Đáp án: B — On-demand + Standard.** IA + on-demand/provisioned sai class cho hot. Câu 79, 348.

## Tổng kết Phần 26

Presigned URL scale upload (506). Global table < 1s (507). NACL deny IP, SG không deny (509). Peering SG không reference cross-Region (510). EKS private = VPC endpoints (514). Provisioned concurrency ≠ reserved (516).
