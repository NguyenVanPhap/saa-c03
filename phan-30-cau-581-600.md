# Phần 30 — Câu 581 đến 600

> Nền tảng: [Chương 0 — Bản đồ hệ thống](00-ban-do-he-thong.md)

---

## Câu 581 — App **stateful**, **luôn ≥ 2** EC2; ASG + HA/fault-tolerant

**Đáp án: B — min 4, 2 On-Demand mỗi AZ** (mất 1 AZ còn 2). Min 2 = mất AZ còn 1. Spot rủi ro. Câu 401.

---

## Câu 582 — Route 53, web on-prem gần us-west-1 **và** eu-central-1, **min load time**

**Đáp án: A — Geolocation:** gần us-west-1 → on-prem; gần EU → eu-central-1. Simple/weighted không tối ưu RTT. Latency policy phải có **cả hai** endpoint, không “associate us-west-1” một mình.

**Tầng 1.**

---

## Câu 583 — 5 PB tape, giữ 10 năm, 6 tháng, 1 Gbps chia sẻ

**Đáp án: C — Snowball + Tape Gateway virtual tape → Deep Archive.** 5 PB / 1 Gbps không kịp 6 tháng. DataSync NFS stage hết chỗ. Backup app ghi thẳng Deep Archive qua 1 Gbps chậm. Tape Gateway online 1 Gbps không đủ 5 PB.

---

## Câu 584 — EC2 parallel, **nhóm node không chung hardware**

**Đáp án: A — Spread placement group.** Dedicated tenancy = host riêng, không “group không share”. Shared tenancy ngược.

---

## Câu 585 — DR phải **có capacity** ở Region failover

**Đáp án: D — On-Demand Capacity Reservation.** RI/SP không bảo đảm capacity. On-Demand không reserve.

---

## Câu 586 — R&D tách Org, đã tạo management account mới

**Đáp án: B — Account R&D **leave** org cũ, rồi **accept invite** org mới.** Một account không thuộc hai org. Tạo account mới + migrate resource nặng.

---

## Câu 587 — Capture activity web app, burst, integrate, **authorization**

**Đáp án: C — API GW + Firehose → S3 + Lambda authorizer.** GWLB không auth. Kinesis Streams thiếu authorizer sẵn như C.

---

## Câu 588 — RDS SQL Server Enterprise, RPO/RTO **24h**, rẻ

**Đáp án: D — Copy automatic snapshot sang Region mỗi 24h.** Replica/DMS chạy liên tục đắt. Native backup 24h cũng được nhưng D là managed RDS.

---

## Câu 589 — ALB sticky, session trên web server; HA, **không mất session** khi 1 web chết

**Đáp án: B — ElastiCache Redis.** Memcached kém persist/replicate. Storage Gateway/RDS thừa session.

**Tầng 6.** Câu 268, 389.

---

## Câu 590 — RDS MySQL size theo ngày; **tháng một lần** report làm chậm

**Đáp án: A — Read replica cho report.** Backup restore/Athena/resize đắt hoặc không realtime.

---

## Câu 591 — EKS, route request tới **đúng microservice**, rẻ

**Đáp án: B — AWS LB Controller → ALB** (path/host L7). NLB L4. API GW/Lambda đắt hơn.

---

## Câu 592 — Ảnh bản quyền, global nhanh, **cấm một số nước**, rẻ

**Đáp án: D — S3 + CloudFront geo restrict + signed URL.** Câu 538.

---

## Câu 593 — ElastiCache Redis HA, không mất data **local + Region**, HA **node và Region**

**Đáp án: A — Multi-AZ Redis replication groups **với shard nhiều node** (cluster mode).** C gần nhưng “more than one read replica” không đủ shard HA. AOF không Multi-AZ. Auto Scaling shard không = HA.

---

## Câu 594 — EC2 On-Demand **lâu launch/load memory** khi test

**Đáp án: C — Hibernate + ASG warm pool.** Giữ RAM trên EBS. Spot/Capacity Reservation không giữ memory state.

---

## Câu 595 — Traffic **tăng đột ngột ngày ngẫu nhiên**

**Đáp án: C — Dynamic scaling.** Predictive cần pattern. Schedule/manual không random.

---

## Câu 596 — PostgreSQL trên EC2, sale tháng **connection** vỡ, traffic **không đoán**

**Đáp án: A — Aurora Serverless v2.** Câu 411, 572.

---

## Câu 597 — Internal API GW + Lambda, **sáng nào cũng latency cao** (cold start)

**Đáp án: B — Scheduled provisioned concurrency** trước giờ làm. Throttle/memory/alarm không giữ ấm.

---

## Câu 598 — Device ghi **SMB**, analyst SQL cả ngày, rẻ (chọn ba)

**Đáp án: A S3 File Gateway, C Glue crawler, F Athena.** FSx File Gateway Windows không data lake. EMR/Redshift đắt query lẻ.

**Tầng 7+8.**

---

## Câu 599 — Outposts: ECS + RDS tại DC khách; team **công ty** chịu gì? (chọn ba)

**Đáp án: A điện+mạng resilient, C physical security DC, F extra capacity ECS cho failure/maintenance.** AWS chịu hypervisor, availability rack, physical maintenance Outposts (B, D, E).

---

## Câu 600 — TCP **nonstandard port**, public, **3 triệu RPS**, latency thấp

**Đáp án: A — NLB public.** ALB L7. CloudFront/API GW không raw TCP cực RPS.

**Tầng 3.**

---

## Tổng kết Phần 30

Stateful min = 2× số AZ tối thiểu (581). Capacity Reservation ≠ RI (585). Hibernate+warm pool (594). Dynamic scale ngày random (595). NLB cho TCP cực RPS (600).
