# Phần 23 — Câu 441 đến 460

> Nền tảng: [Chương 0 — Bản đồ hệ thống](00-ban-do-he-thong.md)

---

## Câu 441 — ASG launch thêm On-Demand khi user tải **static** nhiều

**Đáp án: C — CloudFront + S3 cho static.** Đừng RI/Spot cả fleet vì gốc bệnh là static đi vào EC2.

**Tầng 2.** Câu 328.

---

## Câu 442 — Lake Formation, nhiều account PB, data science **share chọn lọc** cho engineering, ít ops

**Đáp án: D — LF tag-based access control, grant cross-account.** Grant từng user từng account (B) nặng. Copy account chung (A) nhân data. Data Exchange cho publish sản phẩm data, thừa nội bộ.

**Tầng 7.** Câu 341.

---

## Câu 443 — Web toàn cầu, user **upload/download GB**, rẻ, latency thấp

**Đáp án: C — EC2 ASG + CloudFront.** Transfer Acceleration chỉ S3, không host app động. CacheControl trên S3 không tối ưu upload. ElastiCache không phải CDN biên.

**Tầng 2.**

---

## Câu 444 — 2 EC2 một AZ + 1 RDS; nhân viên **xóa DB**, app chết 24h; maximize reliability

**Đáp án: B — RDS Multi-AZ + deletion protection; ALB + ASG nhiều AZ.** Một EC2 + termination protection vẫn SPOF. Spot giảm reliability. Tự dual-write Lambda không phải HA.

**Tầng 4+6.** Câu 401.

---

## Câu 445 — 700 TB NAS, DX 10 Gbps, **90 ngày**, vẫn **access/update** lúc chuyển

**Đáp án: A — DataSync agent, task liên tục lên S3.** Snowball/tape cắt access. rsync tự nuôi, không increment/managed.

**Tầng 8.** Câu 301.

---

## Câu 446 — PDF S3, **giữ 7 năm** legal, object cũ + mới, ít ops

**Đáp án: D — Object Lock Compliance 7 năm + S3 Batch Operations đưa object cũ vào lock.** Governance unlock được. Recopy tay (C) nặng. Versioning+MFA không WORM.

**Tầng 8.** Câu 53, 85.

---

## Câu 447 — Lambda + API GW, đa Region failover

**Đáp án: A — Route 53 health check, active-active failover.** CloudFront origin failover cho HTTP origin, kém “Regional failover API”. TGW/ALB không route API GW đa Region kiểu này.

**Tầng 1.**

---

## Câu 448 — Management VPC: **một** VPN + **một** CGW; Production: VGW + 2 DX; hai VPC **một** peering. Xóa SPOF

**Đáp án: C — VPN thứ hai từ CGW thứ hai vào Management.** Peering thứ hai không tăng HA (peering không failover cặp). VGW thứ hai trên Management không thay CGW đơn. VPN giữa hai VPC không sửa on-prem Management.

**Tầng 9.** Câu 68.

---

## Câu 449 — Oracle + feature bên thứ ba cần **privileged access**, ít người, lên AWS rẻ

**Đáp án: B — RDS Custom for Oracle.** RDS thường không SYS/agent. EC2 tự nuôi đắt ops. Đổi PostgreSQL = viết lại app.

**Tầng 6.**

---

## Câu 450 — App 3 tầng **một server** → Well-Architected (chọn ba)

**Đáp án: C, E, F.** Tách tier, subnet riêng, ASG web/app; ELB + SG tham chiếu tầng; **RDS Multi-AZ**, chỉ SG app vào DB. A giữ “existing architecture” một cục. B/D Single-AZ RDS.

**Tầng 4+6+9.**

---

## Câu 451 — ECS + DX + RDS: team **công ty** quản gì? (chọn ba)

**Đáp án: B, C, F.** Tạo RDS instance + maintenance window; agent/monitor trên ECS; **encrypt in transit trên DX** (customer). AWS quản OS RDS, patch engine, physical DC (A, D, E).

**Tầng 11.** Shared responsibility.

---

## Câu 452 — Job Java EC2, **mỗi giờ 10 giây**, 1 GB RAM, CPU thấp trừ lúc chạy

**Đáp án: B — Lambda 1 GB + EventBridge hourly.** 10s << 15 phút. Fargate vẫn lạnh/start. Stop/start EC2 mỗi giờ vẫn trả EBS+ops.

**Tầng 4.** Ngược Câu 369 (1 giờ).

---

## Câu 453 — Backup EC2 + S3, **retain**, **không sửa** trong hạn (regulatory)

**Đáp án: D — AWS Backup vault lock Compliance.** Governance mở được. DLM không lock S3. File Gateway không WORM vault.

**Tầng 11.** Câu 78, 279.

---

## Câu 454 — Nhiều Region/account, không inventory, **map quan hệ workload**, ít ops

**Đáp án: C — Workload Discovery on AWS** (AWS Perspective). SSM Inventory không vẽ architecture. X-Ray là trace app, không multi-account map.

---

## Câu 455 — Org, budget khác nhau, alert + **tự chặn provision** khi vượt (chọn ba)

**Đáp án: B, D, F.** Tạo budget ở Billing; **IAM role** cho budget actions; alert + action gắn **SCP**. User (C) kém role. Config rule không phải budget action chuẩn.

**Tầng 12.**

---

## Câu 456 — Backup EC2 sang Region 2, **provision** bên đó, quản tập trung, rẻ

**Đáp án: C — AWS Backup cross-Region.** Không nuôi DR fleet sẵn (A/D). Snapshot tay (B) nhiều ops.

---

## Câu 457 — Đẩy data cho manufacturer, **IdP riêng**, protocol **AS2**

**Đáp án: C — Transfer Family (AS2) + Lambda custom IdP.** DataSync/AppFlow/Storage Gateway không phải AS2 B2B.

**Tầng 8.**

---

## Câu 458 — REST API, compute **1 GB RAM + 2 GB storage**, data **quan hệ**, ít admin (chọn hai)

**Đáp án: B Lambda + C RDS.** 1 GB khớp Lambda; 2 GB “storage” = ephemeral/tmp đủ tạm; relational = RDS. EC2/EKS nhiều ops. DynamoDB không quan hệ.

**Tầng 3+4+6.**

---

## Câu 459 — Tag `department` (tagging policy), Cost Explorer **mọi account**, chi EC2 theo phòng

**Đáp án: A — Management account, activate **user-defined** cost allocation tag `department`, report group by tag, filter EC2.** Không phải AWS-defined tag. Member account không thấy org-wide.

**Tầng 12.** Câu 284.

## Câu 460 — Salesforce SaaS ↔ S3, encrypt at rest **CMK**, in transit, API Salesforce đã bật

**Đáp án: C — AppFlow.** Câu 41. Lambda/Step Functions/connector tự viết.
