## Câu 421 — SFTP HA hai EC2 + EIP + shared storage + Linux user; muốn serverless, IOPS cao, security tinh, vẫn control quyền user

- A. Transfer Family + **EBS** (EBS không gắn endpoint Transfer)
- B. Transfer Family + **EFS** + EIP/VPC endpoint internet-facing + SG trusted IP
- C. Transfer Family public + **S3**
- D. Transfer Family **internal-only** private subnet + S3 (user internet không vào)

**Đáp án: B.** “High IOPS” + POSIX-like share + internet trusted IP → EFS + internet-facing VPC endpoint + SG. S3 (C) không phải high IOPS file; D endpoint internal không phục vụ internet. Transfer Family vẫn map user/IAM.

**Tầng 8.** Câu 334.

## Câu 422 — ML microservice, load **1 GB** model từ S3 lúc start, API **async**, usage **lởm** (ngày không ai / batch nghìn request)

- A. NLB → Lambda (1 GB + cold + NLB sync kém async)
- B. ALB → ECS + SQS + **App Mesh scale theo queue** (App Mesh không scale)
- C. SQS → Lambda + “AS scale vCPU Lambda” (không có)
- D. **SQS → ECS**, **AS cluster + service theo độ sâu queue**

**Đáp án: D.** Model 1 GB + start chậm = **container**, không Lambda. Async + burst = SQS. Scale theo queue (Câu 81). Fargate/ECS scale to 0 khi idle.

## Câu 429 — Policy: Allow `ec2:*` nếu Region us-east-1; Deny Stop/Terminate nếu **không MFA**

**Đáp án: D.** Allow mọi EC2 **chỉ us-east-1**. Stop/Terminate **thêm** điều kiện MFA (Deny thắng khi không MFA). Không MFA → vẫn làm EC2 khác (start, describe) ở us-east-1. Không có quyền EC2 Region khác.

**Tầng 10.** Câu 96.

## Câu 430 — Sensor CSV → S3, **đổi thành ảnh ASAP** cho report; ảnh vô nghĩa sau 1 tháng; CSV giữ train ML **2 lần/năm**, audit lên lịch trước hàng tuần (chọn hai)

- B. **Lambda** convert khi upload
- C. Lifecycle: CSV → **Glacier** sau 1 ngày; **expire ảnh 30 ngày**

(A Spot hourly trễ. D One Zone rủi ro CSV. E RRS + IA kém Glacier cho “năm mới đụng 2 lần, biết trước”.)

**Đáp án: B và C.** Train/audit planned weeks ahead → Glacier retrieval chấp nhận được. Ảnh expire 30 ngày.

**Tầng 4+8.**

## Câu 431 — Game, top-10 near real-time, pause/restore giữ điểm

- A. ElastiCache **Memcached**
- B. **ElastiCache Redis**
- C. CloudFront cache scoreboard
- D. RDS read replica tính bảng điểm

**Đáp án: B.** Redis sorted set + persistence (RDB/AOF) — pause/restore còn điểm. Memcached không persist. CloudFront TTL làm bảng điểm trễ. Replica SQL không “near real-time” như Redis.

**Tầng 6.** Câu 268.
