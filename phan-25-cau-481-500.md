# Phần 25 — Câu 481 đến 500

> Nền tảng: [Chương 0 — Bản đồ hệ thống](00-ban-do-he-thong.md)

---

## Câu 481 — ElastiCache phải **luôn khớp** DB khi customer ghi

**Đáp án: B — write-through** (ghi DB và cache cùng lúc). Lazy load có stale. TTL có cửa sổ lệch.

**Tầng 6.**

---

## Câu 482 — 100 GB on-prem → S3, 100 Mbps, encrypt in transit, data mới ghi thẳng S3, ít ops

**Đáp án: A — `aws s3 sync` HTTPS.** 100 GB / 100 Mbps ~ 2–3 giờ. DataSync thêm agent. Snowball thừa. VPN+cp nặng hơn sync.

---

## Câu 483 — Windows container **.NET 6**, mỗi 10 phút, chạy 1–3 phút, rẻ

**Đáp án: A — Lambda từ container image + EventBridge.** 3 phút < 15 phút. Batch/Fargate Windows đắt hơn scheduled Lambda. Task scheduler trên Fargate sai.

---

## Câu 484 — Nhiều account mới, auth **directory tập đoàn** (chọn hai)

**Đáp án: A Organizations all features + E IAM Identity Center tích hợp corporate IdP.** Câu 28.

---

## Câu 485 — Video archive, **hiếm restore**, khi cần **≤ 5 phút**, rẻ nhất

**Đáp án: A — Glacier + Expedited retrieval** (1–5 phút). Standard Glacier 3–5 giờ. IA đắt hơn archive.

**Tầng 8.**

---

## Câu 486 — 3 tầng: static web, container logic, relational DB; đơn giản, rẻ ops

**Đáp án: A — S3 + ECS Fargate + RDS.** CloudFront origin vẫn cần S3. EKS nhiều ops hơn ECS. EC2 static đắt.

---

## Câu 487 — FS mount **nhiều Linux AWS + on-prem** native, HA, scale, **không min size**, đã có VPN

**Đáp án: C — EFS nhiều mount target.** EFS không min size. FSx thường Windows/min capacity. EBS không share on-prem NFS. Một mount target không HA AZ.

---

## Câu 488 — Org all features; billing member **kể cả root member không xem**

**Đáp án: C — SCP deny billing, gắn root OU.** IAM trên member không chặn root member. Đổi consolidated-billing-only mất SCP/all features.

---

## Câu 489 — SNS → HTTPS on-prem warehouse, **một số message mất**; giữ + phân tích **14 ngày**, ít dev

**Đáp án: C — SNS DLQ = SQS, retention 14 ngày.** Đặt SQS *trước* SNS đổi kiến trúc. Kinesis/DDB DLQ không phải target SNS DLQ chuẩn.

---

## Câu 490 — DynamoDB backup S3 **liên tục**, ít code, **không đụng RCU**, không downtime

**Đáp án: B — DynamoDB export to S3 + PITR.** Export không tốn RCU. Stream+Lambda tốn và code. EMR nặng.

**Tầng 6.** Câu 71.

---

## Câu 491 — Async validate thẻ, **at-least-once**, secure, rẻ

**Đáp án: A — Lambda + SQS standard + SSE-KMS + `kms:Decrypt` trên role.** FIFO đắt hơn, đề không hỏi thứ tự. “encryption key invocation permission” sai chỗ.

---

## Câu 492 — Nhiều account dev, staff dựng EC2 **quá khổ**, chặn tập trung, ít dev

**Đáp án: B — Organizations SCP cấm instance type.** Service Catalog/SSM/Lambda phản ứng nặng hơn.

---

## Câu 493 — AI chất lượng cuộc gọi, 4 ngôn ngữ (+ sẽ thêm), **không nuôi ML**; text English + sentiment (chọn ba)

**Đáp án: D Transcribe, E Translate, F Comprehend sentiment.** Polly = TTS. Lex = bot. Comprehend không dịch audio.

**Tầng 4.** Câu 393.

---

## Câu 494 — CLI terminate EC2 → 403; policy Allow Terminate + Deny nếu SourceIp **không** 192.0.2.0/24 và 203.0.113.0/24

**Đáp án: D — request không từ hai dải đó.** Deny thắng. Principal không cần trong identity policy.

---

## Câu 495 — Lake Formation S3, audit PII/hộ chiếu/thẻ

**Đáp án: C — Macie discovery job.** Câu 46, 278.

---

## Câu 496 — On-prem hết chỗ, **block + NFS**, cache local, không re-architect (chọn hai)

**Đáp án: B File Gateway (NFS) + D Volume Gateway (block/iSCSI).** S3 mount/EFS/Snowball không thay cả hai protocol + cache.

**Tầng 8.**

---

## Câu 497 — EC2 private, S3 cùng Region qua **NAT**, giảm **data output cost**

**Đáp án: C — Gateway endpoint.** Câu 42, 72.

---

## Câu 498 — S3 Versioning ảnh, chỉ giữ **2 version mới nhất**, ít ops

**Đáp án: A — Lifecycle noncurrent version expiration, retain 2.** Lambda/Batch ops nặng. Tắt versioning mất mục đích.

---

## Câu 499 — DX 1 Gbps, dùng **< 10%**, giảm cost, giữ security

**Đáp án: D — Partner **hosted connection 200 Mbps**.** Console không tự “đổi 200 Mbps dedicated”. Share 1 Gbps không giảm bill dedicated của bạn.

---

## Câu 500 — Nhiều Windows file server → một FSx Windows, **giữ NTFS permission** (chọn hai)

**Đáp án: A DataSync agent + D Snowcone chạy DataSync.** DataSync giữ ACL. CLI copy S3 mất NTFS. Snowball+S3 rồi DataSync vòng vo hơn.

**Tầng 8.** Câu 301.

---
